`vim-surround` adds surround operations. `vim-repeat` makes normal-mode
surround operations repeatable with `.` while preserving ordinary Vim
repeat behavior. Both are sourced directly by the vimrc; no plugin
manager or external executable is involved.

The Vim license text comes from the system Vim 9.1 `doc/uganda.txt`.
Keep these attribution and license files when copying the bundle.
Updating the bundled code is a deliberate maintenance operation, never
something the editor does on startup.
